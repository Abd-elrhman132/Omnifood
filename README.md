# 🍽️ Omnifood – AI-Powered Food Subscription Website

Omnifood is a fictional AI-powered food delivery service offering healthy, customizable meal plans. This responsive landing page is designed using modern HTML and CSS best practices, with a focus on layout, accessibility, and clean code.

## 🌟 Key Features

- Fully responsive layout for mobile, tablet, and desktop
- Sticky navigation and mobile-friendly menu
- Grid-based sectioning for clean layout
- Testimonial carousel & pricing cards
- Contact form and CTA sections
- Clean, semantic HTML5 and modern CSS

## 🧰 Built With

- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- Mobile-first design principles
- BEM (Block Element Modifier) naming convention
